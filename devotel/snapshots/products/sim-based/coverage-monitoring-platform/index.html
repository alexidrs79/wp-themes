How it works
Four Steps to Complete Network Visibility
Our platform collects real-time network quality data directly from SIM cards, delivering comprehensive and continuous insights into coverage, signal quality, and service failures.
1
Step 1: Deploy SIM Applets
Install monitoring applets on subscriber SIM cards that collect network data including Cell ID, signal strength (RSRP), and technology type without impacting device performance.
2
Step 2: Detect Network Events
Applets automatically detect critical events like call setup failures, dropped calls, network rejections, signal loss, coverage gaps, and technology changes across 2G, 3G, and 4G networks.
3
Step 3: Transmit Data Silently
Event reports are transmitted via silent SMS or OTA data bearers without subscriber interaction. Data transmission works even in idle mode or low-coverage areas.
4
Step 4: Analyse and Optimise
Data can be visualised through comprehensive dashboards showing network performance by location, time, technology, and event type.

FAQ
Got questions about Network Coverage Monitoring?
Everything you need to know about the platform.
What is a Network Coverage Monitoring Platform?
Network Coverage Monitoring is a platform that collects real-time network quality data directly from SIM cards across your subscriber base. It uses lightweight SIM applets to detect and report network events like coverage gaps, call failures and signal degradation, capturing true end-user experience without user participation, or OS-specific tools.
How is this different from traditional network monitoring?
Traditional tools rely on network probes (which miss handset experience), drive tests (costly and limited coverage), or Android apps (excluding iOS and other OS). Our platform monitors all devices regardless of operating system, captures data even in idle mode, operates without user installation, and provides continuous nationwide visibility at a fraction of the cost.
What network events does the platform monitor?
The platform detects call setup failures and dropped calls, SMS failures, network rejections (attach rejects, browser errors), technology changes (2G-3G-4G handovers), signal loss and no-coverage areas, signal quality degradation, timing advance metrics, and distance from cell towers. Each of those events are shown with full context including time, location, Cell ID, and error codes.
Does it require subscriber participation or app installation?
No. Monitoring operates completely through SIM applets that work across all device types without any subscriber intervention, battery impact, or data plan usage. This ensures you capture genuine network experience without selection bias from opt-in monitoring.
What infrastructure is required to deploy this solution?
The platform uses a consistent six-host architecture that scales linearly with subscriber count. For 1M users, you need approximately 60TB storage with six hosts (128GB RAM and 16 cores for two hosts, 64GB RAM and 8 cores for four hosts). The architecture remains the same as you scale to 20M+ users.
How does data transmission work?
Event reports are transmitted via silent SMS or OTA data bearers without subscriber awareness. Transmission works even when devices are idle or in low-coverage scenarios, ensuring comprehensive data collection across all network conditions and locations.
